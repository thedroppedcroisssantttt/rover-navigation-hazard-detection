# Lunar Hazard Rock Detector

A YOLOv8 model trained only on rendered lunar scenes from the Artificial Lunar Landscape Dataset (Pessia, 2019), with
augmentations meant to narrow the gap between rendered and real images.


- Project page: https://thedroppedcroisssantttt.github.io/rover-navigation-hazard-detection
- Code: https://github.com/thedroppedcroisssantttt/rover-navigation-hazard-detection

The license is AGPL-3.0 because the Space runs Ultralytics YOLOv8, which uses that license.
